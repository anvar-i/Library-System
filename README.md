# Library Management System (LMS)
![](img/lib_img.jpg)
University mini project for sharping data structures understanding.

- [DStructures.h](DStructures.h) - is a main header file for algorithms and data structures such as queue and sorting.
- [Menu.h](Menu.h) - is a header to handle console driven menu to navigate through operations
- [main.cpp](main.cpp) - is a main file to run to try library system
